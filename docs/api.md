# API контракт

ZN API построен на FastAPI. Базовый префикс — `/api/v1`.

Все ответы — JSON. Кодировка — UTF-8.

## Конвенции

- **Идентификация объекта** — по кадастровому номеру (`cad_number`).
- Формат кадастрового номера: `XX:XX:XXXXXX:XXX` (регион:район:квартал:участок).
  - Regex: `^\d{2}:\d{2}:\d{6,7}:\d{1,4}$`
- **Геометрия** передаётся в формате GeoJSON (`Feature.geometry`).
- Время — ISO 8601 UTC.
- Ошибки возвращаются в формате `{ "detail": "<message>" }`.

## Коды ответов

| Код | Значение |
|---|---|
| 200 | Успех |
| 404 | Объект не найден |
| 422 | Некорректный кадастровый номер |

## Эндпоинты MVP

### `GET /api/v1/asset/{cad_number}`

Возвращает цифровой двойник объекта (Digital Twin) — полную карточку актива.

**Path параметры:**

| Имя | Тип | Описание |
|---|---|---|
| `cad_number` | string | Кадастровый номер формата `XX:XX:XXXXXX:XXX` |

**Ответ 200 — Asset:**

```json
{
  "id": 1,
  "cad_number": "12:34:567890:123",
  "address": "Московская обл., Одинцовский р-н, д. Раздоры",
  "geometry": {
    "type": "Polygon",
    "coordinates": [[[37.28, 55.73], [37.29, 55.73], [37.29, 55.74], [37.28, 55.74], [37.28, 55.73]]]
  },
  "area": 1500.00,
  "category": "Земли населённых пунктов",
  "owner_type": "private",
  "status": "active",
  "created_at": "2026-07-12T10:00:00Z",
  "updated_at": "2026-07-12T10:00:00Z"
}
```

**Ответ 404:**

```json
{ "detail": "Asset not found" }
```

**Ответ 422 (невалидный кадастровый номер):**

Возвращается стандартным FastAPI validator'ом.

## Плановые эндпоинты (не в MVP)

- `GET /api/v1/asset` — список с фильтрами (регион, площадь, ВРИ, цена)
- `POST /api/v1/watchlist` — добавление в избранное
- `GET /api/v1/watchlist` — список избранного
- `GET /api/v1/search?q=...` — умный поиск
