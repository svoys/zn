# API контракт

ZN API построен на FastAPI. Базовый префикс — `/api/v1`.

Все ответы — JSON. Кодировка — UTF-8.

## Конвенции

- **Идентификация объекта** — по кадастровому номеру (`cad_number`).
- Формат кадастрового номера: `XX:XX:XXXXXX:XXX` (регион:район:квартал:участок).
  - Regex: `^\d{2}:\d{2}:\d{6,7}:\d{1,4}$`
- **Геометрия** передаётся в формате GeoJSON (`Feature.geometry`).
- Время — ISO 8601 UTC.
- Ошибки возвращаются в формате `{ "detail": "<message>" }`.

## Коды ответов

| Код | Значение |
|---|---|
| 200 | Успех |
| 404 | Объект не найден |
| 422 | Некорректный кадастровый номер |

## Эндпоинты MVP

### `GET /api/v1/asset/{cad_number}`

Возвращает цифровой двойник объекта (Digital Twin) — полную карточку актива.

**Path параметры:**

| Имя | Тип | Описание |
|---|---|---|
| `cad_number` | string | Кадастровый номер формата `XX:XX:XXXXXX:XXX` |

**Ответ 200 — Asset:**

```json
{
  "id": 1,
  "cad_number": "12:34:567890:123",
  "address": "Московская обл., Одинцовский р-н, д. Раздоры",
  "geometry": {
    "type": "Polygon",
    "coordinates": [[[37.2845, 55.7321], [37.2855, 55.7321], [37.2855, 55.7331], [37.2845, 55.7331], [37.2845, 55.7321]]]
  },
  "area": 1500.00,
  "category": "Земли населённых пунктов",
  "owner_type": "private",
  "status": "active",
  "created_at": "2026-07-12T10:00:00Z",
  "updated_at": "2026-07-12T10:00:00Z"
}
```

> `geometry` — GeoJSON-объект (`Polygon` в EPSG:4326). `null`, если контур участка не загружен.

**Ответ 404:**

```json
{ "detail": "Asset not found" }
```

**Ответ 422 (невалидный кадастровый номер):**

Возвращается стандартным FastAPI validator'ом.

## `GET /api/v1/search`

Умный поиск активов с фильтрами и пагинацией.

**Query-параметры:**

| Имя | Тип | Default | Описание |
|---|---|---|---|
| `q` | string | — | Текстовый поиск по адресу и cad_number (case-insensitive) |
| `region` | string | — | Код региона (первые 2 цифры cad_number, напр. `50`) |
| `area_min` | number | — | Минимальная площадь, кв.м |
| `area_max` | number | — | Максимальная площадь, кв.м |
| `category` | string | — | Точное совпадение категории (напр. `Земли населённых пунктов`) |
| `status` | string | `active` | Статус актива: `active`/`archived`/`deleted` |
| `limit` | int | `20` | Размер страницы (1–100) |
| `offset` | int | `0` | Сдвиг для пагинации |

Все фильтры комбинируются через AND. `q` ищет через ILIKE по `address` и `cad_number`.

**Ответ 200 — Page[Asset]:**

```json
{
  "items": [
    {
      "id": 1,
      "cad_number": "12:34:567890:123",
      "address": "Московская обл., Одинцовский р-н, д. Раздоры",
      "geometry": { "type": "Polygon", "coordinates": [[[...]]] },
      "area": 1500.00,
      "category": "Земли населённых пунктов",
      "owner_type": "private",
      "status": "active",
      "created_at": "2026-07-12T10:00:00Z",
      "updated_at": "2026-07-12T10:00:00Z"
    }
  ],
  "total": 42,
  "limit": 20,
  "offset": 0
}
```

- `items` — массив объектов Asset (та же схема, что у `GET /asset/{cad_number}`)
- `total` — общее число записей под текущие фильтры (без пагинации)
- `limit`/`offset` — эхо параметров пагинации
