# Принципы разработки ZN

1. Мы продаем решения, а не данные.

2. Каждая функция должна экономить время пользователя.

3. AI должен объяснять свои выводы.

4. Все изменения объектов сохраняются во времени.

5. Любой объект можно анализировать автоматически.

6. Платформа должна работать одинаково хорошо через веб, Telegram и API.

7. Любое решение должно масштабироваться на всю Россию.

8. Архитектура строится вокруг бизнес-сущностей, а не таблиц БД.

9. Код пишется только после описания бизнес-логики.

10. Каждая новая функция должна усиливать ценность подписки.
